# JT-PIAT2
Website Jam'iyyah Tholabah PIAT 2 Majalengka

Setelah masuk Darur Rekap klik "Pilih USB" lalu klik pada folder JTDrive

*Cara upload file ke internet:*
1. Buka Web JT (index.html) terus login
2. Pergi ke Darur Rekap
3. Scroll ke yang paling bawah
4. Di "Ekspor File" klik file yang ingin di ekspor
5. Masuk ke Website JT yang ada di internet (link : jtalirsyad2.github.io/JT-PIAT2/)
6. Login
7. Klik "Ambil dari Drive" (konfig dulu klo belum di konfig)
8. Di "Impor Data dari Excel (XLSX)" klik "Pilih File" lalu upload file tadi ke website, lalu klik "Impor"
9. Ketika sudah diupload klik "Simpan ke Drive"
10. Selesai
